# Teplov Print for AutoCAD

Teplov Print — плагин для поиска форматов в чертежах и пакетной печати в AutoCAD. Он помогает собрать листы из текущего чертежа или нескольких DWG, проверить их перед выводом и сформировать PDF, растровые файлы, DWF либо отдельные DWG.

Текущая версия: **1.0.7**.

## Возможности

### Поиск форматов

- отдельное сканирование **форматов CSoft СПДС** (`SPDSFORMAT`), **форматов из библиотеки** и **прочих прямоугольных форматов**;
- ручной выбор объектов или области в чертеже;
- поиск в модели, на листах, в текущем пространстве либо во всех пространствах;
- сканирование одного или нескольких внешних DWG-файлов;
- повторное сканирование добавляет новые листы к текущему списку без дубликатов;
- распознавание замкнутых полилиний и, при необходимости, рамок из четырёх отрезков;
- игнорирование выключенных, замороженных и непечатаемых слоёв;
- чтение наименования, номера листа, даты, редакции и стадии из атрибутов, текста и форматов СПДС.

### Форматы и масштаб

- распознавание стандартов A0–A4, удлинённых и пользовательских форматов;
- автоматическое определение масштаба по геометрии формата;
- ручная команда **«Изменить масштаб формата»** для одного или нескольких выделенных листов;
- выбор A0–A4 с отдельным пересчётом масштаба для каждого листа — A1 и A3 не получают ошибочно одинаковый масштаб;
- настраиваемая точность сопоставления бумаги, пользовательские масштабы и правила именования удлинённых форматов.

### Пакетная печать

- вывод в **PDF, PNG, JPG, DWF и DWG**;
- выбор устройства вывода и таблицы стилей CTB/STB; в nanoCAD — выбор принтера для PDF в списке «Принтер» рядом с CTB;
- печать с прозрачностью, толщинами линий и настраиваемым полем по краю;
- предварительный просмотр листа средствами CAD;
- печать выбранных листов, исключение строк из списка и изменение порядка;
- пространственная сортировка и перенумерация листов;
- печать нескольких DWG с корректной обработкой листов, видовых экранов и внешних ссылок;
- пакетное разбиение чертежа на отдельные DWG по найденным форматам.

### PDF и имена файлов

- настройка шаблона имени с номером листа, наименованием и другими полями;
- автоматическое добавление номера, если PDF с таким именем уже существует;
- объединение отдельных PDF в один файл;
- при необходимости — отдельный объединённый PDF для каждого размера листа;
- сохранение исходных отдельных PDF после объединения;
- закладки объединённого PDF по имени файла или по **наименованию листа**;
- открытие итогового PDF или папки результатов после окончания печати.

### Библиотека и ведомость

- добавление форматов в библиотеку и управление библиотекой;
- импорт и экспорт библиотеки в JSON;
- настройка границы печати и резервных областей текста для каждого типа формата;
- создание ведомости листов в текущем чертеже;
- настройка столбцов, размеров ячеек, стиля, высоты текста, слоя и оформления ведомости;
- обратная запись изменённых наименований и номеров в поддерживаемые форматы CAD/СПДС.

## Установка

1. Закройте AutoCAD.
2. Запустите `Teplov-Print-AutoCAD-Setup-1.0.7.exe` от имени администратора.
3. Инсталлятор разместит плагин в стандартной папке AutoCAD `ApplicationPlugins`; при следующем запуске AutoCAD он загрузится автоматически.
4. Откройте меню **Teplov** → **Пакетная печать**.

Для ручной загрузки используйте команду `NETLOAD` и выберите DLL, подходящую вашей версии AutoCAD. При предупреждении безопасности добавьте папку плагина в `TRUSTEDPATHS` согласно правилам вашей организации.

### Ручная установка без инсталлятора (AutoCAD 2021, nanoCAD 24/25)

В каждом [выпуске](../../releases) есть архив `Teplov-Print-manual-install-v<версия>.zip`. Он устанавливается без прав администратора — все файлы размещаются только в профиле пользователя (`%APPDATA%`):

- AutoCAD — `%APPDATA%\Autodesk\ApplicationPlugins\TeplovPrint.bundle`, плагин загружается автоматически;
- nanoCAD 24 и 25 — `%APPDATA%\TeplovPrint\nanoCAD24\NcadBatchPlot.dll`, загрузка через `NETLOAD`/`APPLOAD`.

Пошаговая инструкция — в файле `INSTALL.md` внутри архива ([installer_manual/INSTALL.md](installer_manual/INSTALL.md)).

### Печать в nanoCAD 24 и 25

В AutoCAD PDF, PNG, JPG и DWF печатаются через плоттеры комплекта `LA_pdf.pc3`, `LA_png.pc3`, `LA_jpg.pc3` и `LA_dwf.pc3`. Это конфигурации AutoCAD с драйверами Autodesk, поэтому в nanoCAD они не устанавливаются: PDF (и PNG/JPG, которые получаются из PDF) печатается через встроенный PDF-плоттер nanoCAD, DWF — через DWF-плоттер nanoCAD. Принтер для PDF (и PNG/JPG) выбирается в списке **«Принтер»** главного окна — он расположен под списком CTB и показывается только в nanoCAD (issue #13). В списке перечислены устройства печати nanoCAD, кроме «Нет» и плоттеров `LA_*.pc3`. Выбранный принтер запоминается в настройках и используется также в окне универсальной пакетной печати и командой `ZBP_SINGLE_PLOT`; для DWF и DWG список недоступен. Пока принтер не выбран или если выбранный принтер больше не установлен, плоттер выбирается автоматически: имя из переменной окружения `TEPLOV_PRINT_PDF_DEVICE` (задаётся до запуска nanoCAD, как имя показано в окне «Печать» nanoCAD), иначе встроенный PDF-плоттер nanoCAD.

- Принтеры Windows (например, «Microsoft Print to PDF» или физический принтер) печатают через свой драйвер: такой принтер может сам запросить имя файла или отправить лист на бумагу, а список форматов бумаги у него свой. Для пакетной печати в файлы удобнее PDF-плоттеры nanoCAD.
- Виртуальные PDF-принтеры Windows (например, PDFCreator или Adobe PDF) при печати в файл записывают не PDF, а PostScript своего драйвера. Такой файл плагин преобразует в PDF через Ghostscript (issue #15): сначала берётся Ghostscript, который входит в PDFCreator (`<папка PDFCreator>\Ghostscript\Bin\gswin64c.exe`), затем установленный GPL Ghostscript (`C:\Program Files\gs\gs*\bin`). Другой Ghostscript можно указать в переменной окружения `TEPLOV_PRINT_GHOSTSCRIPT` (путь к `gswin64c.exe` или к его папке, задаётся до запуска CAD). Если Ghostscript не найден или принтер записал данные не в PostScript (например, PCL лазерного принтера), печать листа завершается понятной ошибкой с подсказкой; формат и начало файла записываются в журнал печати.

Пользовательские и удлинённые форматы бумаги в nanoCAD не добавляются в конфигурацию плоттера: используется ближайший формат PDF-плоттера nanoCAD, а лист вписывается в него. Преобразование текста в геометрию в nanoCAD задаётся настройками его плоттера.

Печать в nanoCAD выполняется через COM API nanoCAD (`Document.AcadDocument`): параметры задания (плоттер, формат бумаги, окно печати, поворот, масштаб, стиль печати, веса линий) записываются в активный лист (`ActiveLayout`), лист печатается командой `Plot.PlotToFile`, после чего листу возвращаются прежние параметры печати. Управляемые `PlotFactory`/`PlotEngine` nanoCAD 24 и 25 не выполняют печать (их методы пустые), а запись параметров в лист через `PlotSettingsValidator` в версии 1.0.3 приводила к закрытию nanoCAD без сообщения (issue #9). Если nanoCAD отклоняет параметр, в отчёте указан шаг, на котором произошёл отказ (например, `ActiveLayout.StyleSheet = monochrome.ctb: COMException 0x80004005: …`).

Одна и та же `NcadBatchPlot.dll` работает в nanoCAD 24 и 25: обе версии запускают плагины на .NET 6, а все члены API nanoCAD, которые вызывает плагин, есть в nanoCAD 25 и реализованы там (это проверяют тесты `NanoCad25CompatibilityTests`), поэтому отдельная сборка для nanoCAD 25 не нужна.

- Свойство `Plot.QuietErrorMode` плагин не задаёт: в nanoCAD оно не реализовано, и на каждом листе появлялось окно «COM / NOT_IMPLEMENTED / CPlotObj::put_QuietErrorMode» (issue #11).
- Если nanoCAD отвечает `TYPE_E_LIBNOTREGISTERED` (0x8002801D, «Библиотека не зарегистрирована») — библиотека типов COM API nanoCAD не зарегистрирована в Windows, — плагин один раз за сеанс находит её среди модулей nanoCAD и регистрирует для текущего пользователя (`RegisterTypeLibForUser`, без прав администратора), после чего повторяет шаг. Найденные библиотеки и результат регистрации записываются в журнал печати. Если это не помогло, восстановите установку nanoCAD (Параметры Windows → Приложения → nanoCAD → Изменить → Восстановить, от имени администратора) и перезапустите nanoCAD.

### Журнал печати

При каждом нажатии «Начать печать» создаётся журнал `%TEMP%\TeplovPrint-print.log`; новая печать заменяет предыдущий журнал. В журнал записываются версии плагина, CAD, .NET и Windows, параметры печати, все листы задания, каждый шаг настройки и вывода (до его выполнения), ошибки с типом, HRESULT и стеком, а также необработанные исключения. Каждая строка сразу сохраняется на диск, поэтому если CAD аварийно закроется, последняя строка журнала покажет шаг, на котором это произошло. Путь к журналу показывается в итоговом сообщении печати.

## Основной порядок работы

1. Выберите источник: «Форматы CSoft СПДС», «Форматы из библиотеки», «Прочие форматы» или «Ручной выбор».
2. Нажмите «Сканировать чертёж», «Сканировать выбор» либо «Печать из файлов».
3. Проверьте список листов, формат и масштаб. При необходимости выделите строки и нажмите «Изменить масштаб формата».
4. Выберите тип вывода, путь, устройство, CTB и остальные параметры.
5. Нажмите «Начать печать».

## Сборка

Требуются Windows, .NET SDK из `global.json` и восстановленные NuGet-пакеты (reference assemblies AutoCAD и nanoCAD подключаются из NuGet).

```powershell
dotnet build LA.BatchPlot.sln --configuration Debug
```

Результаты сборки:

- `bin-acad/AcadBatchPlot.dll` — AutoCAD 2015–2024;
- `bin-acad2025-2027/AcadBatchPlot.Core.dll` — AutoCAD 2025–2027;
- `bin-nanocad24/NcadBatchPlot.dll` — nanoCAD 24 и 25.

Каждый push собирается в GitHub Actions (`.github/workflows/build.yml`): DLL для AutoCAD 2021 и nanoCAD 24/25 доступны как артефакты сборки. После изменения `<Version>` в `.csproj` и слияния в основную ветку автоматически публикуется выпуск `v<версия>` с ZIP-архивами.

Инсталлятор собирается отдельной командой Inno Setup:

```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" "installer_acad\LA-BatchPlot-AutoCAD.iss"
```
